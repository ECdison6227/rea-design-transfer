# 验证范围

## 本仓库检查

```sh
npm ci --ignore-scripts
npm run validate
npm test
```

格式检查核对技能名称/目录、YAML、UI调用元数据和全部Markdown本地引用。它不证明Agent一定做出优秀设计；Python官方quick_validate.py可用时额外运行，不为检查安装全局Python依赖。

Design Package脚本无第三方运行依赖；合成测试覆盖三种原平台draft初始化、拒绝覆盖、profile导出、核心缺口/readiness、显式D适配保留原coverage、A/B与独立实现分离、配对证据、引用、哈希变化、动效声明/未知、非正常格式及路径/符号链接边界。测试内容是合成fixture，不是真实截图或REA调用。

可选research-manifest的检查与原有9组合成测试沿用总库先前草案，保留来源/参考、捕获时间、用户接受与研究状态、精确分发和字节检查边界。Design Package是消费者设计格式，不替代底层run/capture记录。

## 独立情境试用

重大修改可按skill-creator进行独立前向试用：向试用Agent提供技能、真实任务和最少原始材料，不提供预设答案/怀疑点，在隔离目录完成可支持交付，禁止未授权的设备、网络和原件修改。结果应区分实际产物、格式检查和真实原版运行。

本次独立试用只提供三张历史手机截图、对应scene原记录和一份反编译代码；禁止原App运行、联网、安装依赖及修改原件。试用Agent实际交付partial标准包：17 tokens、5组件、2布局、4交互、2未知动效和8证据记录，保留原采集时间与未知制品绑定；没有把有限资料升级为完整设计研究，也没有伪造REA调用来通过入库门禁。

该试用发现4处检查器漏检：partial缺少implementation、非法implementation状态、unknown easing带确定值、悬空researchEvidenceRefs。修复后对同四份原负例重跑，全部按预期被拒绝；原真实partial包仍通过完整性检查。另补充采集区间/单点时间及未绑定B片段的表达，避免格式迫使填伪精确时间或冒称制品归属。

当前27组合成回归通过。独立试用证明了有限历史资料下的标准交付与消费者边界处理，没有证明所有平台都能自动运行或新的完整产品迁移已通过。试用原件和私人本机路径不进入本公共仓库。

## 历史验证

0.1版本做过受限历史资料/源码锚整理、仅截图能力和已有规范迁移的独立情境审读。未产生新原版运行或证明所有平台都可自动提取。新版本保留A/B/C/D、原时间/条件及原始资产边界，增加视觉优先、标准交付和总库接口。

技能仓库保持原URL，新技能名称为rea-design-transfer。旧rea-style-library调用迁移到新名；安装前备份旧目录到发现范围外。GitHub推送与本机安装的具体提交/检查在实际完成后报告，不以文档中出现命令当执行成功。
