# 验证范围

## 结构校验

运行`npm ci`、`npm run validate`检查技能的YAML、命名、必需字段、UI调用元数据与本地引用。开发依赖只有YAML解析器，不要求安装额外工具链来读取或使用skill。

校验器使用Node.js，不等于执行skill-creator的Python校验器。格式正确也不证明研究结果正确。

## 独立场景试用

开发时使用独立Agent，在受限临时目录进行试用。没有联网、控制目标App、安装工具、运行新REA分析或修改目标工程。没有产生新运行观察；原始试用资料和个人路径不包含在本仓库中。

1. 根据两张历史桌面截图、元数据与有限源码锚，整理迁移到文件管理业务的风格片段。产出了profile、来源与未知、规则映射、目标事件契约和下一Agent入口，没有复制聊天功能或把历史截图称新实测。
2. 对“指定网站但仅有截图能力”的场景评估行动。区分REA技能和可调用工具，不假称截图证明DOM、交互或动画，也不把未访问的URL称已验证不可达。
3. 对“已有库与源码、只有浅色证据”的场景评估迁移路线。优先目标技术栈和已有证据，不追无关同步协议；暗色作为明确补证任务或目标独立选择。

试用促成了以下修订：新增历史原始资料整理模式；区分有限交接与完整风格库；A覆盖不足时仍标部分验证；增加`origin: historical|current`与采集/复核时间和条件匹配字段。

## 尚未证明的能力

该试用支持有限证据下的交接、业务替换和边界判断。它没有验证所有手机、桌面和网站环境，也没有完成新网站采集、目标软件实际改造、完整来源对照或跨业务运行验收。

使用本skill研究具体产品时，仍须针对该产品采集、验证并报告覆盖；不能用此仓库的结构校验或试用结果代替。
