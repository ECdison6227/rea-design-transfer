# 阶段、依赖与接入

## 默认范围

默认提取完整可迁移的设计语言，核心是视觉元素、组件/布局/状态、关键动效和通用交互。研究维度用于发现独特类型，不直接展开成全部业务功能测试。

每次扩展先回答：它补充什么新的设计类型、参数或体验规则？已有同类样本充分时转向核心缺口。原业务清单与设计覆盖单独保存，按用户最新明确目标判断必要项。

| 阶段 | 可审查结果 | 下一步/停止依据 |
| --- | --- | --- |
| 身份与目标 | 版本/平台/来源、用户用途、核心设计地图与已有资料 | 缺失会改变范围的信息才询问 |
| 登录协作（适用时必需） | 用户可操作的登录入口、有效会话与认证影响的界面范围 | 已有有效会话直接继续；否则请用户登录，不能默认跳到游客页partial |
| 真实样本与追证 | 核心类型的原图/操作状态、对应资源和关键未知 | 局部已可实施即做参考，不等原业务全测 |
| 参考与规格 | 可复用组件/布局切片及同条件对照，补设计差异 | 先修影响后续页面的字体/尺寸/壳/输入问题 |
| 标准包与迁移 | Design Package v1、资产使用入口、小型不同业务切片 | 核心设计有规格、实现/对照与适配范围 |
| 交付与恢复 | 单一入口、验证、核心/可选缺口、环境恢复 | 必要目标已满足可收口；其余依赖明确时交付partial及继续条件 |

仅资料整理/比较/入库不新增原版GUI运行、参考或跨业务工程。已有规范用于实施时，只补影响目标的设计缺口。

## 状态与依赖

研究覆盖、迁移就绪、约定目标分别表达。用户接受边界不改变原研究的未测事实；明确要求的全功能验证仍保留其必要条件。未知主要字体/几何/动效且影响核心还原时不能仅靠填字段称ready。

先判断依赖属于目标身份、工具/运行环境、正常认证、服务容量、真实设备或采集方法。正常认证按[研究的登录协作](research.md)处理：核心设计需要认证时先主动请用户登录；用户已答应或正在登录时保持待续，不把等待超时当成拒绝或研究完成。用户完成后核对有效会话，继续补证，不只更新一个“已登录”标记。

其他技术依赖给出与风险相称的有界复试和退出条件；无新条件不重复同类失败。用户明确延后协助时记录依赖、已试路线和继续条件，不每轮重新催问。登录相关partial必须说明用户拒绝/延后、公开页范围约定或具体认证障碍；“未登录”本身不是跳过协作的理由。

必要依赖受阻时继续独立的资产、规格、参考或整理。全部剩余核心项都受阻时保存可审查partial与恢复入口。技术归因不应无限深入到对设计实现没有影响的部分。

## 旧研究与统一库

旧库可以保留README/library.json及原有文件名。新增design-package.json时映射逻辑入口，逐步补标准模块；不能把旧文档换名后假称已完成新格式或更高覆盖。

原版平台分类为web/desktop/mobile，运行栈与参考平台另记。REA入库需要来源身份、实际REA研究入口/输出与清楚的证据边界；普通UI项目不会因有界面就变成REA研究。来源内的迁移例子跟随其来源，不独立增加原版数量。

用户指定总库时遵从其AGENTS和普通目录结构；不要另建子模块/分析仓库。保留独立风格、原始历史和运行方式，不为统一入口重写所有工程或混合tokens。

## 记录与完整性

复用当前可靠采集工具，目标、run ID、端口、输出目录和分发选择放配置；不每轮复制改名整套硬编码脚本。可选[research-manifest](../assets/research-manifest.json)及[离线检查器](../scripts/check-manifest.mjs)记录run/capture/coverage；它与面向设计消费者的Design Package是不同层次，不强迫所有平台使用同一种捕获驱动。

原件不覆盖，每次新run/capture ID；一台设备/窗口一个主动控制者。PNG与UIA/DOM分次采集标非原子，各通道保留时间和状态差异。锁仅约束采用该锁的工具，不代表全系统控制权。

首次核对来源身份后复用可靠清单，只检查本轮新增/变更/引用的文件。完整性检查证明声明的字节与引用，不证明像素正确、真实后端、授权或全功能通过。

## 分发与续接

原件留存、Git提交及公开导出分别审查。标准包默认private；不把原包、凭据、profile、私人画面或未经审核资产自动提交。仅在已授权的范围同步GitHub，保持仓库既有私有性。

交付的相对入口需在消费者实际得到的目录中可解析；遗漏原件保留metadata和原因，不依赖本机绝对路径或未分发的原包。对公开导出核对实际成员，不把某个manifest通过当整个归档都已审核。

续接记录给出当前目标、核心/可选缺口、已完成阶段、依赖与继续条件、控制者、版本及启动/验证命令。本轮配置按原值恢复并核对；无法确认的初态或账号有效期保留未知，不宣称精确恢复。
